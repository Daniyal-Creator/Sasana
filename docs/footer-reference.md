# Redesign Footer SASANA — Professional, Minimal, and Purpose-Driven

## 1. Analisis Footer Saat Ini

Footer pada desain sekarang masih sangat minimal:

```text
[Shield] Photos are never stored.

Not affiliated with the Bali government.
Reference: Governor Circular No. 7/2025.

Home    About

[N floating logo/button]
```

Secara fungsi sudah cukup, tetapi secara visual masih terasa seperti bagian tambahan setelah landing page selesai.

Masalah utama:

- Tidak memiliki hierarchy yang kuat.
- Terlalu banyak ruang kosong tanpa struktur visual yang jelas.
- Link navigasi terlalu sedikit dan tidak memiliki grouping.
- Disclaimer dan privacy statement terlihat seperti informasi terpisah, bukan bagian dari sistem footer.
- Floating button/logo di kiri bawah terasa tidak terintegrasi dengan footer.
- Tidak ada closing statement atau brand identity yang membuat website berakhir dengan memorable impression.
- Footer belum memanfaatkan tema SASANA, Bali, dan sacred-site guidance.

### Tujuan redesign

Footer baru harus terasa:

- Professional
- Calm
- Premium
- Trustworthy
- Minimal
- Consistent dengan visual utama SASANA
- Tetap ringan dan tidak terasa seperti footer template SaaS

---

# 2. Konsep Utama: Editorial Closing Footer

Gunakan pendekatan:

> **Editorial Closing Footer**

Footer bukan sekadar tempat copyright dan link.

Footer menjadi **closing statement** dari pengalaman user.

Struktur:

```text
Closing Statement
        ↓
Navigation + Product links
        ↓
Trust / Privacy information
        ↓
Copyright + Disclaimer
```

Visualnya tetap sederhana, tetapi memiliki hierarchy yang jelas.

# 11. Decorative Element

Tambahkan **satu decorative visual** yang sangat subtle.

Karena tema SASANA berkaitan dengan Bali dan sacred sites, opsi terbaik:

### Option A — Fine sacred geometry

Garis geometris tipis dengan opacity rendah.

### Option B — Topographic line

Pattern garis kontur yang terinspirasi peta.

### Option C — Botanical line

Garis botanical minimal pada salah satu sudut.

### Option D — Temple silhouette

Silhouette pura sangat tipis di background bawah.

Rekomendasi utama:

> **Topographic / sacred geometry line**

Karena lebih universal dan tidak membuat desain terlihat terlalu ornamental.

# 12. Jangan Membuat Footer Terlalu Tinggi


Tinggi tersebut cukup untuk:

- Brand statement
- navigation
- trust information
- copyright

Jika menggunakan dekorasi, jangan sampai footer menjadi terlalu tinggi.

# 15. Navigation Interaction

Navigation footer harus sederhana.

Normal:

```text
Home
```

Hover:

```text
Home →
```

atau:

```text
Home
────
```

Gunakan transition pendek.

Contoh:

```css
.footer-link {
    transition:
        color 0.2s ease,
        transform 0.2s ease;
}

.footer-link:hover {
    transform: translateX(3px);
}
```

Jangan membuat hover effect terlalu besar.

# 18. Floating Button / Logo

Pada screenshot terdapat floating circular element:

```text
      ┌─────┐
      │  N  │
      └─────┘
```

Jangan biarkan elemen ini berdiri sendiri tanpa konteks.

Ada dua pilihan.

### Option A — Integrasikan ke Footer

Letakkan logo/monogram sebagai bagian dari brand footer.

Ini pilihan yang direkomendasikan.

### Option B — Jadikan Floating Utility

Jika tombol memang mempunyai fungsi seperti:

- scroll to top
- accessibility
- quick navigation

maka tetap floating, tetapi harus memiliki fungsi yang jelas.

Jika hanya logo dekoratif, jangan floating.

---

# 19. Scroll-to-Top

Jika elemen floating memang dimaksudkan untuk kembali ke atas:

```text
↑
```

gunakan icon arrow-up yang jelas.

Posisi:

```text
bottom: 24px
right: 24px
```

dan gunakan circle dengan:

```text
background: #14283B
border: 1px solid ...
```

Ini jauh lebih komunikatif daripada hanya menampilkan monogram.

# 23. Accessibility

Footer wajib tetap memiliki semantic structure:

```html
<footer>
    <nav aria-label="Footer navigation">
        ...
    </nav>
</footer>
```

Gunakan heading untuk grouping:

```html
<h3>Explore</h3>
<h3>Features</h3>
<h3>About</h3>
```

Semua link harus memiliki:

- meaningful label
- visible focus state
- sufficient contrast

Jangan membuat navigation hanya berupa icon.

# 25. Core Design Rules

Footer final harus mengikuti beberapa aturan:

### 1. Jangan membuat card

Footer tidak membutuhkan card.

### 2. Gunakan whitespace

Whitespace menjadi komponen utama.

### 3. Gunakan typography untuk hierarchy

Heading, link, disclaimer, dan copyright harus memiliki ukuran berbeda.

### 4. Gunakan satu decorative language

Pilih salah satu:

- topographic
- sacred geometry
- botanical
- subtle temple silhouette

Jangan semuanya.

### 5. Pertahankan trust messaging

Informasi:

> Photos are never stored.

dan

> Not affiliated with the Bali government.

tetap harus mudah ditemukan.

### 6. Integrasikan brand

Footer harus terasa seperti bagian dari SASANA, bukan komponen yang ditempel di akhir.
